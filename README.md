# Vehicle Frontend

React + Vite frontend for the Vehicle Parking System backend.

## Features

- Dashboard-style UI
- Create vehicle records
- Edit existing records
- Delete records
- Search and filter vehicles
- Pagination support
- Backend health check display

## Setup

1. Install dependencies:

```bash
npm install
```

2. Configure the API base URL:

```bash
copy .env.example .env
```

Default backend URL:

```env
VITE_API_BASE_URL=http://localhost:5000/api
```

3. Start the app:

```bash
npm run dev
```

4. Build for production:

```bash
npm run build
```
